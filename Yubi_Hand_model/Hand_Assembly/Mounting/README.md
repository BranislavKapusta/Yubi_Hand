\# Mountings for Different Applications



Mounting system for my hand project. The repository consists of two parts:



\- \*\*Hand\_Mount\_p1\*\* – an adapter (reduction) for the palm of the hand, allowing easy connection (an "easy connector").

\- \*\*Mounts\*\* – different mount variants for attaching various applications to the adapter.



\## UR3s 50 mm Mounts



```

UR3s 50 mm

├── Type 1 – full mount with the exact 4 holes

├── Type 2 – 45° offset, 2 holes, for easier mounting

└── Type 3 – 45° offset, 2 free slotted holes, to compensate for different sizes

```



\### Spacers



For each type, a 1 mm spacer is available. The spacer can be scaled in your slicer to compensate for different bolt lengths.
